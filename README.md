# 🎬 Motion Studio Portfel və Avtomatlaşdırma Platforması

Müasir veb texnologiyaları və mikroservis arxitekturası ilə qurulmuş yüksək məhsuldarlıqlı, real vaxt rejimində işləyən kreativ portfel və avtomatlaşdırılmış video istehsalı platforması.

## 🚀 Texnologiya Yığını (Tech Stack)

- **Backend:** C#, .NET 10, ASP.NET Core, SignalR, Entity Framework Core
- **Verilənlər Bazası və Mesajlaşma:** SQL Server, RabbitMQ
- **Frontend:** HTML5, CSS3, JavaScript, Swiper.js, GSAP
- **Video Emalı:** Node.js, Remotion (sosial media Reels/TikTok şablonlarının avtomatlaşdırılmış video renderinqi üçün)
- **DevOps və Yerləşdirmə (Deployment):** Docker, Docker Compose, DigitalOcean Ubuntu Server, Nginx, ngrok

## ✨ Əsas Xüsusiyyətlər

- **Real vaxt rejimində Canlı Dəstək və Çat:** Müştərilər və admin komandası arasında ani mesajlaşma üçün ASP.NET Core SignalR ilə təchiz olunub.
- **Dinamik Layihə Vitrini:** Video oynatma idarəetmələri ilə interaktiv portfel şəbəkəsi.
- **Avtomatlaşdırılmış Story Sistemi:** 24 saat ərzində avtomatik silinən statuslar və story izləyicisi.
- **Müştəri İdarəetməsi və Sorğular:** Təhlükəsiz müştəri qeydiyyatı, xüsusi büdcə kalkulyatoru və sifariş statusunun izlənməsi.
- **Responsive Tünd/İşıqlı Dizayn:** Motion dizaynerlər və kreativ studiyalar üçün uyğunlaşdırılmış müasir kosmik estetika.
